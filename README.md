# Разходка из стария Търново

Сайтът показва улици от Велико Търново като Gaussian splats в браузъра. Gaussian splats са облак от малки полупрозрачни цветни петна, които заедно изглеждат като 3D сцена. Разходката е от първо лице, с дълбочина на рязкост, преход от ден към нощ и автопилот. Сайтът използва three.js и Spark.

## Стартиране

Инсталирайте зависимостите и стартирайте сървъра за разработка:

```bash
npm install
npm run dev
```

Отворете `http://localhost:5199`. Без параметри сайтът генерира процедурна улица във Варуша директно в браузъра.

## Готови сцени

Сцените са в `public/scenes`. Всяка сцена има файл `.spz` и файл `.json` със стартовата камера и маршрута на автопилота.

| Адрес | Сцена |
| --- | --- |
| `/?splat=/scenes/arcades.spz&cine` | Аркадите на Самоводската чаршия, финален вариант, 2 милиона splats |
| `/?splat=/scenes/arcades-draft.spz` | Същите аркади, пробен вариант |
| `/?splat=/scenes/samovodska.spz` | Цялата Самоводска чаршия, около 180 m, пробен вариант |
| `/?splat=/scenes/tarnovo-atlas.spz&cine` | Измислена уличка във Варуша с изглед към Царевец |

Параметърът `&cine` пуска автопилота. Без него се движите с WASD и мишката, а с Q и E се качвате и слизате. Клавишът P пуска и спира автопилота.

Визуализаторът показва най-много 1,2 милиона splats наведнъж. Ако искате повече детайли, добавете `&budget=2000000`. Параметърът `&q=high` вдига ограничението до 2,5 милиона splats, колкото Spark дава по подразбиране, и рисува в пълната резолюция на екрана.

Можете да пуснете и свой файл `.spz`, `.ply` или `.splat`. Плъзнете го върху страницата или натиснете O.

## Как са направени сцените

Сцените са направени с World Labs Atlas API и CLI `worldlabs`. Скриптовете и заявките са в папката `atlas`.

1. `atlasTextToImage` рисува картина по описание. Само сцената `tarnovo-atlas` използва тази стъпка.
2. `images2PosedRGBD` изчислява камерата и дълбочината на всяка снимка.
3. `atlasGenerate` дорисува нови гледки между снимките, с дълбочина.
4. `posedImages2Splats` слепва всички гледки в един файл `.spz`.

Скриптовете `make_*.py` четат отговорите на Atlas (`*-op.json`). Тези отговори не са в хранилището, защото съдържат подписани връзки и идентификатори на акаунта. Ако искате да повторите стъпките, изпълнете ги с вашия акаунт в Atlas.
